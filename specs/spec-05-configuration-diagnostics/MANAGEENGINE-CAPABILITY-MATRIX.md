# SPEC-05 — Matriz ManageEngine, Wave 3

Fecha: 2026-11-27. Proveedor confirmado: **ManageEngine**. El adaptador GEOPS corresponde a Mobile Device Manager Plus MSP Cloud. La edición, licencia, versión, región, scopes y URL del **tenant actual** no se comprobaron: no hay grant de lectura en este worktree ni consulta autenticada. El antiguo Trial MSP Cloud no acredita el tenant actual. Ninguna capacidad se marca `VERIFIED` contra tenant y ninguna escritura está habilitada.

Estados: `VERIFIED` exige evidencia del tenant actual; `DOCUMENTED_NOT_VERIFIED` indica documentación oficial o prueba sintética; `CONSOLE_ONLY`, `NOT_SUPPORTED` y `LICENSE_RESTRICTED` exigen evidencia específica del entorno; `UNKNOWN` indica que aún no puede decidirse. Un 403/404 no prueba por sí solo ausencia de API.

El adaptador usa OAuth solo en backend, `X-CUSTOMER` del cliente autorizado, origen HTTPS fijo y errores sanitizados. Las lecturas parciales conservan `SCOPE_DENIED` o `UNAVAILABLE` por sección. Los IDs `fake-*` nunca se envían al proveedor.

**Wave 5 web:** el portal reutiliza `/v1/admin/mdm/capabilities` y `/devices/:id/configuration` para presentar estas capacidades y hallazgos con estado de evidencia. El dashboard entrega `compliance:null` mientras el tenant real no esté verificado. El listado distingue vínculo de inventario GEOPS↔ManageEngine de lectura real de perfiles; una asociación de inventario no prueba permiso aplicado. La vista previa y solicitud local conservan el gate de escritura, sin cambiar ninguno de los estados de esta matriz.

**Gate de escritura:** documentar producto, modalidad, edición, licencia, versión, región, scopes READ/CREATE/UPDATE, modo Android Enterprise y perfil objetivo; leer el tenant de laboratorio, comprobar alcance individual y obtener autorización específica. `submit` permanece cerrado. No se modifica política operativa ni se automatiza la consola.
