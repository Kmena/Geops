## Hallazgos que cambian el diseño

1. La edición Free admite 25 dispositivos según ManageEngine; **la API para esa edición no está verificada**. Se mantiene un adaptador MDM separado y una vía manual provisional solo si el dueño del producto la aprueba. [R02–R03]
2. WorkManager sirve para subir datos diferidos, no para capturar cada minuto. El servicio de ubicación maneja la captura, sujeto a permisos y restricciones de arranque. [R07–R10]
3. El mapa no debe depender operativamente de teselas/Overpass públicos para volumen empresarial. [R11–R12]
4. La escala inicial no exige particionado ni cola externa; se medirá y se podrá evolucionar sin romper IDs de eventos. [R13–R14]
5. El protocolo de identidad usa claves Android Keystore y PoP; managed configuration/UDID ayudan a vincular, pero no bastan para autenticar. La disponibilidad real de ese canal en Free sigue pendiente. [R18–R19]

La búsqueda documental no equivale a haber probado un tenant ManageEngine ni teléfonos reales. Esas dependencias siguen en [risks.md](risks.md) y [open-questions.md](open-questions.md).
